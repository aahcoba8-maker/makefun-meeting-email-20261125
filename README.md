## Entry

One line, 98 characters, one joke about a meeting that should have been an email:

> The agenda had one item: 'discuss the email.' Forty-five minutes later, nobody had read the email.

## How it works

`main.py` (stdlib only) writes the line to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` when set, otherwise next to the script. It
self-checks the scorer gate before writing: 1–200 characters, a
single line, not blank.

Run it:

```sh
python3 main.py
```
